# Secure AI systems without losing the security foundations

An AI security engineer protects AI adoption, agent integrations and sensitive data.

**Field:** Security & governance · **Classification:** AI-focused specialty · **Foundations:** Cybersecurity, Cloud security

<span id="what-changes-and-what-remains"></span>

## What you do

Expand threat models to cover prompt injection, tool permissions and shadow AI. Build secure integrations and guardrails, investigate risks, and turn research prototypes into maintained tools and services with security, research and product teams.


## Skills

- Threat modeling for agents, connectors and model hosting.
- Secure APIs, reusable tools and backend services.
- Cloud/data protection and automated guardrails.
- Security validation, scripting and remediation workflows.
