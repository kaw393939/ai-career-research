# AI Agents & Automation Engineer

AI agents and automation engineers connect models, tools and business workflows through software.

**Classification:** Overlapping employer title · **Foundations:** Process analysis, Backend development

**Also search:** applied AI, AI software engineering, agent engineering, automation development

<span id="how-this-role-is-changing"></span>
<span id="what-the-work-means"></span>

## What you do

Integrate tools and data, orchestrate workflows, test uncertain outputs, and explain results to users. Probabilistic tool selection adds permission and evaluation concerns. Agent work overlaps application engineering and customer delivery rather than defining a separate entry-level profession.

<span id="skills-to-investigate"></span>

## Skills

- Programming, APIs and process analysis.
- Tool integration, workflow orchestration and integration tests.
- Model-output evaluation and error handling.
- Stakeholder demonstrations, release notes and user guides.

<span id="compare-the-career-stages"></span>

## Example requirements

**T-Mobile — Summer 2027 Assoc AI Engineer Internship:** mentored AI decision-workflow projects accepting foundational coursework/project evidence; requires continuing enrollment, **age 18+** and **US work authorization**. A broad applied-AI internship does not guarantee agent-specific work.

**Bitdeer — 2027 US AI Engineering, New College Graduate:** tool integration and orchestration are among possible tracks, with separate eligibility and assignment conditions. **C3 AI — Forward Deployed Engineer – Federal, New Grad 2027:** enterprise applications, debugging, demonstrations, training and LLM tool calling alongside senior engineers; the employer specifies graduation windows, **US citizenship, clearance eligibility and on-site attendance**.

**MANTECH — Automation AI Developer:** enterprise agents, prompts, implementation, testing, demonstrations and documentation. This is explicitly a **future opportunity — status uncertain**, not a confirmed immediate opening. Requires **3+ relevant development years**, enterprise-agent/LLM-workflow experience, **US citizenship and Public Trust**; remote work may involve client travel. Python, REST, vector databases and RAG are **preferred**, not all mandatory.

<span id="portfolio-practice-an-auditable-workflow"></span>

## One project

**Auditable request-routing workflow.** Use synthetic records and label the customer scenario as simulated.

1. Define a **20-case test set** and scoring rubric before building.
2. Demonstrate a tool call, malformed input, failed dependency and uncertain result routed to human review.
3. Explain which actions require approval and what actually executes.
4. Publish observed failures, release notes and a user guide; distinguish simulation from measured outcomes.
