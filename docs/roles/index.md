# Find the work that fits you

AI careers involve much more than training models. Some engineers build products, some deliver customer projects, and others test how systems behave. Use the responsibility you want to take on as your starting point.

This comparison is an editorial synthesis of the employer and official role descriptions linked in each profile. It describes common patterns, not universal job requirements. Research reviewed **November 5, 2026**.

## Compare the roles

| Role | Main question | Typical work | Useful portfolio evidence |
| --- | --- | --- | --- |
| [AI engineer](./ai-engineer) | How do we make AI useful in a product? | Application code, model integration, evaluation, deployment | A working AI feature with a test set and documented limitations |
| [Forward-deployed engineer](./forward-deployed-engineer) | How do we solve this customer's actual problem? | Discovery, integration, implementation, adoption | A deployed workflow built around a realistic stakeholder brief |
| [LLM engineer](./llm-engineer) | How do we make a language model application reliable? | Retrieval, tool use, inference, evaluations | A retrieval or agent workflow with baselines and failure analysis |
| [ML engineer](./ml-engineer) | How do we run and maintain a useful model? | Data pipelines, training, serving, monitoring | A reproducible model pipeline with validation and monitoring |
| [AI evaluation engineer](./ai-evaluation-engineer) | How do we know the system is good enough? | Test design, measurement, error analysis, release gates | A versioned evaluation suite with scoring guidance and regression reports |
| [AI solutions architect](./ai-solutions-architect) | What system should the organization build? | Requirements, cloud design, tradeoffs, technical guidance | An architecture proposal with a working prototype and cost model |

## Choose by the problems you enjoy

- **You like building software:** start with [AI engineering](./ai-engineer) and [LLM engineering](./llm-engineer). Compare how much the job asks you to work on the application versus model infrastructure.
- **You like working directly with people:** explore [forward-deployed engineering](./forward-deployed-engineer). Read carefully for travel, production ownership, and experience requirements.
- **You like data and reliable systems:** investigate [ML engineering](./ml-engineer). Training knowledge, data quality, deployment, and monitoring often matter together.
- **You like finding why things fail:** explore [AI evaluation](./ai-evaluation-engineer). Strong software skills and careful measurement both help.
- **You like connecting technical decisions to business needs:** read about [AI solutions architecture](./ai-solutions-architect). Many positions expect experience with cloud systems and customer communication.

## What job titles can hide

An AI engineer may build a product at one employer and advise customers at another. A forward-deployed engineer can work on AI projects or on other kinds of software. An evaluation role can focus on product tests, research, safety, or data operations.

ML engineering and solutions architecture existed before the current generative AI wave. The atlas groups established and emerging responsibilities together to help you compare work; it does not claim all six titles are newly invented occupations.

## Use a job description as a research document

Before deciding whether a role fits, extract five things:

1. **Deliverable:** what must this person ship, improve, or maintain?
2. **Users:** who will rely on their work?
3. **Skills:** which are required, preferred, or simply mentioned?
4. **Constraints:** what experience, location, travel, or authorization does the description specify?
5. **Evidence:** what project or past experience could show you can do similar work?

Compare several descriptions from different employers. A single listing shows one organization's needs; it cannot establish the requirements of an entire profession.
