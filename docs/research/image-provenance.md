# Illustration provenance

**Generated November 5, 2026**, using the built-in image generation tool through the imagegen skill. No API-key workflow was used. The output was visually inspected and copied into the project as `docs/public/images/career-learning-workflow.png`; the original generated file was retained.

The [learning guide](./visual-guide) labels the image as an AI-generated editorial illustration and supplies descriptive alternative text. It illustrates exploring fields, building a project, testing it, and sharing evidence. It is not a photograph of NJIT students, an employer endorsement, a data chart, or evidence of career outcomes. All numerical charts are rendered separately from verified data.

## Final prompt

> Use case: illustration-story. Asset type: explanatory editorial illustration for the existing AI Career Atlas student learning roadmap. Create a wide horizontal hand-drawn editorial illustration that explains a concrete workflow: a student at a desk explores three technical work areas (a small network of connected computers, a shield beside a server, and a software application window), then builds a small project on a laptop, then tests it with a checklist and shares a simple project notebook. Arrange the workflow left to right with subtle connecting paths. Warm ivory background, forest green linework, muted sage and small ochre accents, gentle paper texture, clear uncluttered composition suited to a career research website. Diverse human characters, ordinary realistic laptops and notebooks. No text, numbers, charts, statistics, logos, employer branding or watermarks. This is a conceptual illustration, not evidence or a factual infographic.

The image was generated with an opaque background and no input/reference images.
