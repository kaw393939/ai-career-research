# Turn coursework into evidence

This is an editorial learning map for NJIT students, based on the **2026–2027 B.S. Computer Science catalog**, reviewed November 5, 2026. It is not an official advising plan or a promise of eligibility for a job.

Your degree requirements depend on your own catalog year and program. Check prerequisites, availability, concentration rules, and your schedule with [YWCC academic advising](https://computing.njit.edu/advising). A listed course is not a guarantee that it is offered in a particular semester.

## Pick a foundation, then demonstrate it

Course numbers and names below come from the [official BSCS catalog](https://catalog.njit.edu/undergraduate/computing-sciences/computer-science/bs/). Skill and portfolio connections are our interpretation.

| Career interest | Catalog topics to discuss with an advisor | Portfolio evidence to build |
| --- | --- | --- |
| AI application / model work | CS 370 Introduction to Artificial Intelligence; CS 375 Introduction to Machine Learning; CS 474 Introduction to Generative AI | A small application, fixed evaluation set, baseline and failure report |
| Cloud / AI platforms | CS 343 Introduction to Cloud Computing; CS 443 AI Systems and Infrastructure; CS 455 Introduction to GPU Cluster Programming | A model-serving pipeline with a load test and measured bottlenecks |
| Networking | CS 356 Introduction to Computer Networks; CS 357 Network Security: Attacks & Defenses | A simulated network with automated connectivity tests and a recovery demonstration |
| Security / responsible AI | CS 351 Introduction to Cybersecurity; CS 408 Introduction to Cryptography; IS 350 Computers, Society and Ethics | A threat model, access controls, test results and an explanation of remaining risks |
| Data engineering / analytics | CS 331 Database System Design & Mgmt; MATH 333 Probability and Statistics | A reproducible SQL/Python pipeline with data-quality checks and an analysis report |
| Systems / performance | CS 288 Intensive Programming in Linux; CS 332 Principles of Operating Systems | A benchmark and documented resource/failure investigation |
| Technical communication / customer delivery | YWCC 307 Professional Dev in Computing; COM 312 Effective Communication or COM 313 Writing in the Workplace | A user brief, demo, decision log and understandable handover guide |

## Compare concentrations without assuming a career outcome

The current catalog lists **AI: Learning and Reasoning**, **AI: Systems and Infrastructure**, and **Cybersecurity and Privacy** concentrations. Their published descriptions emphasize different foundations; they do not confine graduates to a single job title. Discuss elective choices with an advisor rather than treating this map as degree-audit advice.

## Use the support that already exists

[NJIT Career Development Services](https://www.njit.edu/careerservices/) provides career-planning and preparation support and links to [NJIT Handshake](https://njit.joinhandshake.com/). Use the public CDS page to confirm current resume support, appointments and opportunity-search guidance. Handshake may require an NJIT login; this project does not access private listings or guarantee appointments or placement.

Bring two role profiles, a draft portfolio case study, and questions about degree/timing restrictions to a career conversation. Compare [all technology fields](./roles/), then use [job eligibility checks](./jobs/) to distinguish an interest from an application target.
